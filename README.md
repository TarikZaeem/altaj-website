# شركة التاج المميزة — الموقع الإلكتروني

موقع شركة التاج المميزة بالرياض لتصنيع وتوريد أحواض النباتات البلاستيكية ومستلزمات المشاتل وأحواض الديكور منذ 2010.

مبني بـ React و Vite و Tailwind CSS و Three.js، ويدعم العربية والإنجليزية والوضع الفاتح والداكن.

## التشغيل على جهازك

**المتطلبات:** Node.js 20 أو أحدث

- على ويندوز: اضغط مرتين على `start.bat`
- أو من الطرفية:

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`

## النشر

أي تعديل يُرفع على فرع `main` يُبنى وينشر تلقائياً على GitHub Pages عن طريق
`.github/workflows/deploy.yml`.
